大狗短信（中国 +86 用户）

对接大狗短信 V1.0.5。仅 +86 中国大陆 手机号走此通道；菲律宾/东南亚等走下方 Universe Action 国际短信。

签名规则：参数 ASCII 排序拼接后加 &key=密钥，MD5 大写。可先填参数点测试，无需先保存。

Universe Action 国际短信（非中国用户）

对接 UNAL/AboSEND 国际短信 API。菲律宾、印尼、越南、马来西亚、柬埔寨等 +86 以外号码走此通道。凭据从企业后台 HTTP 对接获取 orgCode、MD5Key、网关域名。

占位符 {code} 为验证码。国际短信建议英文模板。
发送签名：MD5(orgCode+content+rand+md5Key) 大写；余额签名：MD5(orgCode+rand+md5Key) 大写。可先填参数点测试，无需先保存。
高级：通用 HTTP 网关（备用）
