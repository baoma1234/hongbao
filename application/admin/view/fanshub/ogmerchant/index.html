联调：注册玩家

调用 POST /api/v2/platform/transfer-wallet/register（form）；S-100 / S-121 成功。前端对齐：player_id = u{user_id}。

联调：玩家转账 · 存入

调用 POST /api/v2/platform/transfer-wallet/deposit（JSON + signature）。S-100 成功（含 balance）；S-101 流水重复视为已入账；S-104 玩家不可用会先重注册再试。后台联调仅打 OG，不扣本站红宝；正式走 /api/fanshub/ogdeposit。

联调：玩家转账 · 提出

调用 POST /api/v2/platform/transfer-wallet/withdraw（JSON + signature）。S-100 成功（含剩余 balance）；S-101 流水重复视为已提出；S-103 余额不足。后台联调仅打 OG，不加本站红宝；正式走 /api/fanshub/ogwithdraw。

联调：转账历史

调用 GET /api/v2/platform/transaction/transfer-history。S-100 有数据；S-115 无数据。正式前端走 /api/fanshub/ogtransferhistory（会按当前用户 player_id 过滤并同步本站）。

联调：游戏列表

调用 GET /api/v2/platform/game/game-list。正式/沙箱 game_id 不同，上线请用正式网关重新拉取。前端：/api/fanshub/oggamelist。

联调：限红列表

调用 GET /api/v2/platform/operator/betlimit。正式/沙箱限额组 id 不同。前端：/api/fanshub/ogbetlimit。

联调：进入游戏

调用 GET /api/v2/platform/games/launch（query + signature，时间戳毫秒）。正式前端：/api/fanshub/oglaunch。

联调：玩家余额

调用 GET /api/v2/platform/transfer-wallet/get-balance。S-100 返回 current_balance；S-104 玩家不可用。正式：/api/fanshub/ogbalance。

联调：投注记录

调用 GET /api/v2/platform/transaction/history。S-100 返回 records；S-115 无数据。勾选落库会写入本地并供后台搜索。
